# 决策与范围

- 用户本轮要求优先于建立指南的全功能清单：仓库根为 BioCache，包名为 biocache，不另建 Paper_NIPS_27/neural_kv。
- 依据两份 Markdown 明确的拓扑实现每层二维片、相邻列稠密连接、同步旧状态更新和软重置。没有收到引用的《工作设计.pdf》，未将其内容作为已经独立核验的事实。
- 本轮最小验证包含拓扑与传播、合成 KV 存储与延迟读取。真实 VLM trace 收集、逐层蒸馏和模型替换列为后续工作。不创建看似完成但不能运行的真实模型空入口。
- PyTorch 为 CUDA 12.8 构建，同时保留 CPU 默认实验。GPU 设备需要显式指定，不自动占用全部 GPU；测试只做小规模 CUDA 前后向。
- 默认 C=4、N=64、S=4；tau=[16,64,256,1024]、threshold=0.5、训练步数100是预先选择的工程起点，不是论文结论或最优超参数。
- 当前用线性带符号电流投影；正负双通道、位置嵌入网络及训练集归一化暂未加入。数据直接用其原始尺度，无验证集拟合统计。
- 合成实验同时训练独立的 first/last/all 读出与轻量探针。全列输入更多、参数更多，必须按实际参数量解释差异；没有把它描述为完全匹配参数预算。
- 预登记主要判据：三个种子的测试均值中，末列 attention MSE 相比清零/打乱两对照均至少下降20%；对照接近零时用配置的绝对容差。报告每种数据/延迟/干扰模式，整体通过要求所有非零延迟条件都通过。失败保留原指标，不事后改阈值。
- 该判据属于工程初筛，不做有限样本显著性或一般泛化定论。分别记录传播机制是否正确、存储与读取实验是否完成，以及存储质量判据是否通过。
- P0/P1 框架仅完成实验所需子集；无完整 toy causal Transformer、精确缓存/路由/融合，不宣称完整 P0/P1 通过。P2/P3 未完成，部分合成消融先用于存储与延迟读取测试。
- GitHub 仓库默认为私有；文档、代码、精简实验结果和环境锁定文件提交，checkpoint/完整逐种子输出只保留本地 outputs。
