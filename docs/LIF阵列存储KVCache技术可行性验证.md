# LIF 三维阵列存储 KV-Cache：技术可行性验证方案

> 目标：验证 KV 信息能否经首列输入，在 LIF 阵列中逐列传播，并在有限状态中保留可被未来 Query 读取的信息。
> 依据：同目录《工作设计.pdf》及用户补充的阵列连接定义。与《Agent代码框架建立指南.md》配套，本文只研究每片内部的列间连接。
> 本文是待执行的实验方案，参数和验收阈值是建议起点，尚无实测结论。

## 1. 唯一采用的拓扑

整个 LIF 阵列具有三个几何轴：

- **层轴 L**：对应 VLM 语言解码器的 Transformer 层，不是视觉编码器层。
- **列轴 C**：每片二维阵列中，从输入侧到末列的传播方向。
- **行轴 N**：每列包含 N 个标量 LIF 神经元。

第 l 层 Transformer 的 K/V 只写入第 l 片二维结构，整体状态为 `[B,L,C,N]`。B 是 batch 轴，不是几何轴；KV head 先由本层编码器联合处理，不引入额外的神经元几何维度。

```text
                       列 0        列 1                 列 C-1
Transformer 0 KV ──>  [N 个 LIF] ══> [N 个 LIF] ══> … ══> [N 个 LIF]  片 0
Transformer 1 KV ──>  [N 个 LIF] ══> [N 个 LIF] ══> … ══> [N 个 LIF]  片 1
        …                        各片间没有突触连接
Transformer L-1 KV →  [N 个 LIF] ══> [N 个 LIF] ══> … ══> [N 个 LIF]  片 L-1
```

每个 `══>` 是 N×N 的全连接：前一列的每个神经元连接下一列的全部神经元。当前不建立同列、反向、跳列或跨片突触。这是相邻列全连接，不是片内任意神经元间全互连。单神经元保持自己的膜电位，不等于新增突触连接。

本验证不得添加跨层连接。完整框架中可以将其标为未来研究方向，但不纳入本轮效果或参数统计。

## 2. 首选模型：SmolVLM2-500M-Video-Instruct

推荐 `HuggingFaceTB/SmolVLM2-500M-Video-Instruct`。它是 500M 级模型，支持图像、多图、视频与文本输入，适合先收集真实视觉 KV，再做短视频历史检索实验。其官方模型卡标注英语，因此初步问答使用英语，减少语言能力对存储验证的干扰。[官方模型卡](https://huggingface.co/HuggingFaceTB/SmolVLM2-500M-Video-Instruct)

Transformers 的 SmolVLM 文档提供图像 / 视频处理及加载示例；本轮使用官方 processor 和 chat template，固定实际安装版本及模型 revision。模型支持视频不代表它天然具有本方案的有界在线记忆，流式缓存仍需自行实现。[官方 Transformers 文档](https://huggingface.co/docs/transformers/model_doc/smolvlm)

执行时先检查配置，再确定层数、head 数、head dimension 和 RoPE 位置。不要根据“500M”猜测层数或把语言主干参数量当作整个多模态模型参数量。不要将模型卡的推理显存用作本实验训练显存保证；教师 KV、训练图和优化器均带来额外开销。

建议使用 PyTorch 进行原型验证；CPU 执行小阵列单元实验，实际 VLM trace 收集与训练优先用可用 GPU。首版使用便于观测 QKV 的 eager / 显式注意力路径，锁定兼容的依赖版本。没有硬件时交付合成实验结果并将真实模型验证标记未完成。

## 3. 分开回答五个问题

| 问题 | 必须获得的证据 | 单独不足以证明什么 |
|---|---|---|
| P1：传播 | 孤立输入依次引发各列响应 | 不证明记住了 KV |
| P2：保持 | 停止输入或加入干扰后，状态仍包含可读信息 | 非零膜电位不等于有效记忆 |
| P3：读取 | 未见 Query 的 attention 输出近似误差降低 | 训练集拟合不代表泛化 |
| P4：压缩 | 状态字节数有界且低于对应历史 KV | 隐藏保存全 KV 不算压缩 |
| P5：模型可用 | 替换真实模型历史缓存后问答 / logits 可接受 | 离线教师 QKV 不能证明闭环推理 |

额外核心问题：**末列是否承载有效历史信息，而非只有活动**。必须单独用末列读取做检验；全列读取不能掩盖末列失效。

## 4. 精确定义输入与更新

### 4.1 输入编码

本层单个 token：`K_l,V_l ∈ R^(Hkv×Dh)`。本层独立编码器：

```text
x[l,t] = Encoder_l(concat(vec(K[l,t]), vec(V[l,t]), position, timestamp))
x[l,t] ∈ R^N
```

K/V 为带符号连续值。首版使用可训练线性 / 小 MLP 电流投影，不强行 ReLU 丢弃负值。补充实验比较正负双通道编码，必须将双通道消耗计入 N。标准化的统计量只来自训练集。

保持真实 token 顺序，将一个 token 作为一次外部事件。首版不聚合多个 token，避免将输入聚合误差与 LIF 存储误差混淆。视觉 token 来自 processor 实际展开后的映射；保留 frame、patch、原始位置标签供监督和诊断，标签本身不能在读取时泄漏答案。

### 4.2 同步微步方程

令 `s` 为内部微步。一次外部 token 事件执行 S 个微步，仅首个微步向列 0 注入 x。所有列从旧状态同步计算：

```text
I[l,0,s] = x[l,t] if s == 0 else 0
I[l,c,s] = W[l,c-1] @ spikes_old[l,c-1], c = 1,...,C-1
u_pre[l,c] = exp(-delta_micro / tau[l,c]) * u_old[l,c] + I[l,c,s]
spikes_new[l,c] = H(u_pre[l,c] - threshold[l,c])
u_new[l,c] = u_pre[l,c] - threshold[l,c] * spikes_new[l,c]
```

`W ∈ R^[L,C-1,N,N]`，其中行列分别对应输出与输入神经元。阈值、tau 为正。软重置每微步只执行一次。无输入时仍可以通过上一微步脉冲向后传播，且所有膜电位继续衰减。

从零状态开始，若首列在第 1 个微步发放，则第 c 列最早在第 c+1 个微步响应；末列最早在第 C 个微步响应。**S≥C 是允许一次事件内到达末列的时间条件，不是必然激活保证。** 不得原地遍历列，使同一脉冲在一个微步穿越整片。

列末无新层可传递不意味着信息永久保存：末列仍泄漏、发放和重置。首版不设置末列无限精度累积器，也不额外保存全部历史输出。

### 4.3 时间与微步预算

建议 `C=4, N=64, S=4` 起步，再扫描 `C∈{2,4,8}, N∈{32,64,128}`。微步总时间记为 `Delta_event`，`delta_micro=Delta_event/S`。tau 使用相同时间单位。

比较不同 S 时，首先固定 `Delta_event`，以免把更长物理时间误认为传播收益。另做固定 `delta_micro` 的实验时必须单独标记。每个 token 处理 S 次会增加延迟；不得在统计之外偷偷追加稳定 / 刷新微步。

孤立脉冲实验允许输入后使用零输入 flush；连续流实验默认不 flush，验证不同事件在阵列中重叠传播时的干扰。暂停流时是否推进动力学、推进多少，均作为明确输入时间记录。

## 5. 实验顺序

### E0：不加载 VLM，验证拓扑和单次传播

使用单片阵列，零初态，向首列注入单个已知向量。先构造可控 W、阈值确保通路能发放，再使用随机 / 可训练参数测试。

必须输出各列膜电位热图、发放 raster、首次发放时刻和活动率。将第 l 片输入清零 / 替换，确认其他片状态完全不变。将一对相邻列 W 置零，零初态下其后所有列不能因本次输入而响应。

验收：时延符合微步规则、没有 NaN、软重置正确、片间独立。该阶段只证明传播机制。

### E1：合成 KV 的存储与保持

建立可控的 KV 关联检索流，至少包含：低秩重复背景、彼此可区分的随机关联、短暂唯一事件、相似 Key 对应不同 Value。划分独立训练 / 验证序列，不在读取端提供原历史 KV。

先输入一段历史，再执行两种延迟：零输入等待、持续干扰输入。测量延迟 0/16/64/256 个外部事件时的可读信息；同时报告微步数和时间。

三种读取方式：

1. **末列读取**：`Z_last = [u[:,-1,:], spikes[:,-1,:]]`；核心检验。
2. **全列读取**：`Z_all = [u, spikes]`；估计阵列整体信息保存上限。
3. **首列读取**：相同读取器容量；判断传播是否提供价值。

先训练轻量探针恢复预设事件标签 / Value，再训练 Query-conditioned attention readout。若需要完整序列重构作为诊断，必须指定长度与读取地址，并报告读取器参数，不能将输出长度增长伪装为有界内部缓存。

验收：延迟后的末列读取显著优于零状态 / 打乱状态对照，且对独立测试序列有效。膜电位不衰减或活动持续本身不计为通过。

### E2：收集真实 0.5B VLM 的逐层 trace

冻结模型，准备短多图 / 视频序列，先确认完整 KV 的模型能回答所选问题。保存每层实际 Q、K、V、attention 输出和位置映射，记录模型 revision、processor、采帧、图像 token 数与种子。

trace 仅为离线教师数据，不是部署缓存。至少先选择浅、中、深三个层独立验证，再扩展到所有 Transformer 层一一对应的二维片。少数层通过不能称为全模型通过。

未来 Query 可以作为训练监督目标，但不能作为过去编码器的输入。历史写入时不得读入未来问题。先校验禁用压缩时参考 attention 与模型输出一致，并明确 K 为 RoPE 前 / 后。

### E3：按层训练列传播与 Query 读取

训练每层 encoder、列间 W、tau / threshold 及 readout；主干冻结，使用代理梯度与截断 BPTT。先用所有历史视觉 token 写入 LIF，关闭语义路由，避免精确分支掩盖 LIF 本身的失败。

```text
Y_teacher = softmax(Q_future @ K_history.T / sqrt(Dh)) @ V_history
Y_hat = Readout_l(Q_future, Z_l)
L = mean(||Y_teacher - Y_hat||²)
```

主实验为末列读取；全列读取作为对照。建议读取器将状态生成固定 M 个 latent K/V，再用原层 Query 检索；M 固定并记录参数量。latent K 不是恢复出的原始 K，需明确其位置编码约定。

报告分层 MSE、相对 L2、训练 / 测试差距和按回溯距离分组的指标。相对 L2 分母加 epsilon，同时报告 teacher 输出范数，避免低范数放大误差。

额外分开报告：全历史注意力、仅远期历史注意力；否则近期 token 的强贡献可能掩盖远期记忆丢失。

### E4：真实模型内替换

先替换一层，再多层，再全部层。只用 hook 采集 trace 不算替换成功。使用显式 attention wrapper，使原 Q 真正读取 LIF 状态；释放被替代的完整历史 KV。

本阶段可恢复一个固定近期精确窗口，文本保留策略保持一致。先不加入复杂语义路由；报告相同近期窗口的无长期记忆基线。比较末列和全列读取的融合，空状态时使用精确分支。

按逐 token 因果参考顺序：当前注意力读取合法精确 KV 及旧 LIF 状态 → 产生输出 → 迁移已过近期窗口的 KV → 向本层首列写入。新块不得先全量写入再读取块中较早 Query。

测试实际学生 Query 与误差累积，不能只复用教师 Query。图片 / 视频 processor 的分块追加必须验证与固定原始位置的参考路径一致；离线整段视频推理不等于在线流式验证。

## 6. 必须有的对照与消融

| 对照 | 目的 |
|---|---|
| 完整 KV | 质量上界参考与原模型任务能力检查 |
| 同近期窗口、无 LIF | 证明收益来自历史状态 |
| 相同状态字节数的 EMA / 线性递推阵列 | 区分 LIF 阈值发放的贡献 |
| 首列 / 末列 / 全列读取 | 区分传播、末列有效性和整体记忆 |
| 断开一对列间连接 | 检查末列确实依赖传播链 |
| 打乱 / 清零状态 | 排除读取器仅靠 Query 或数据先验猜答案 |
| 随机冻结 W 与可训练 W | 判断学习连接是否必要 |
| 不同 C、N、S、tau、阈值 | 确定传播衰减、饱和与成本边界 |

比较列数时，固定 N 会同时增加状态和参数，必须另做固定总神经元数 C×N 的实验。末列与全列读取器的输入维度不同，报告参数量，尽量匹配隐藏层和参数预算，避免读取器容量造成误判。

## 7. 指标、资源与建议判据

### 7.1 实际保存了什么

持久运行态至少包括 `u`、当前 `spikes`、时间戳、有效标记及精确缓存。`u` 为 FP32、spikes 为 bool 时，基础状态约为 `B*L*C*N*(4+1)` 字节，以实际 tensor dtype 为准。若 spikes 用 float32 则不能按 bool 统计。

列间 W 参数量为 `L*(C-1)*N²`，并加入 encoder/readout 参数。它们属于静态模型开销，与持久缓存分别报告，但都要计入总内存。训练再计梯度、优化器、截断计算图、教师内存；推理计临时激活和峰值。

完整 KV 对照：`2*B*L*T*Hkv*Dh*bytes_per_element`。长期状态与输入长度无关只是有界性；必须在足够长的 T 下证明总开销和误差的实际取舍。不得将 500M 权重大小当作全部运行内存。

列间稠密传播成本每事件约 `O(L*S*(C-1)*N²)`，另加编码读取成本；发放稀疏不自动减少密集矩阵乘开销。

### 7.2 建议预先登记的试验判据

以下是启动实验用的工程判据，可在正式运行前调整；不得看结果后无说明地修改：

- E0：拓扑和因果延迟测试全部通过，其他片状态不受单片输入影响。
- E1/E3：至少 3 个种子；独立测试集上末列读取 MSE 比零 / 打乱状态对照下降至少 20%，报告均值和标准差。若对照误差接近零，改用预登记的绝对容差。
- E3：对浅 / 中 / 深层分别给出结果；未通过层如实列出，不只报平均值。
- E4：预先固定例如 100 个小规模诊断问题，完整 KV 必须先具备可测的任务能力；压缩后相对完整 KV 准确率下降建议不超过 5 个百分点，并优于相同近期窗口基线。样本少时报告置信区间，不作泛化定论。
- 内存：流长度提高 10 倍后，饱和状态字节数不增长；另检查容器和计算图泄漏。逐项报告压缩比及端到端峰值，不能只看公式。
- 延迟：报告写入 S 个微步、读取和整段推理的耗时；即使慢于基线也保留结果。

以上判据通过表示在指定设置下具有初步可行性，不等于已证明长期精确存储、一般视频任务有效或端侧加速。

## 8. 失败定位

| 现象 | 首先检查 / 后续动作 |
|---|---|
| 首列发放、末列无响应 | 列间权重、阈值、符号、S、同步时序；先用受控脉冲排错 |
| 全列都发放但读取无效 | 饱和、同质化、reset 信息损失；看状态区分度和探针结果 |
| 全列可读、末列不可读 | 列传播瓶颈 / 信息衰减；不能宣称末列存储成功 |
| 静止时可读、干扰后遗忘 | 状态覆盖；扫描容量和时间尺度，记录可保留回溯长度 |
| 随机 KV 失败、低秩背景成功 | 容量或数据结构限制；界定适用范围，不声称无损 |
| 教师 trace 成功、在线生成失败 | 学生 Query 分布变化、多层累积误差、位置或融合错误 |
| LIF 不优于 EMA | 保留负面结果，重新审视脉冲机制是否必要 |
| 状态有界但总内存 / 延迟变差 | 列间 N² 参数、微步和读取器成本；缩减结构而非隐藏开销 |

配置必须显式包含：

  columns: 4
